# An Android Exchange client (Samsung Email / Nine style), protocol 14.1,
# base64 query.
#
# Built, not recorded. Sources: [MS-ASHTTP] v20250520 2.2.1.1.1.1 (the
# base64 query: version, command code, locale, device id, device type,
# parameters), [MS-ASCMD] section 4 (4.2 Autodiscover in its mobilesync
# form, 4.4 FolderSync, 4.5 Sync with a window, 4.7 SmartReply, 4.8 Ping,
# 4.9 GetItemEstimate), [MS-ASPROV] 4.1 and [MS-ASAIRS] (plain-text bodies
# cut to a size). The client's habits are as publicly known, not checked
# against a capture: Autodiscover POX first, protocol 14.1, DeviceType
# "Android", a one-week filter, plain text with truncation, and an
# estimate before the first sync.

@device androidc1234567890 Android Android-Mail/2025.1 14.1 base64

!autodiscover pox
contains <Type>MobileSync</Type>
contains /Microsoft-Server-ActiveSync</Url>
