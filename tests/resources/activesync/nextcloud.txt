# Calendars, contacts, tasks and notes through the DAV bridge, as iPhone
# (16.1) uses them, against a throwaway Nextcloud (run by
# tools/activesync/test-bridge-nextcloud.sh; skipped without one).
#
# Built, not recorded. Sources: [MS-ASCMD] v20250520 4.5.3 (adding an
# item), 4.5.4 (changing one), 4.5.5 (deleting), 4.5.2 (Fetch), 4.8 (Ping),
# 4.17 (MeetingResponse), [MS-ASCAL] 2.2.2 (calendar elements), [MS-ASCNTC],
# [MS-ASTASK], [MS-ASNOTE] (their examples' shapes).

@device ApplDAVTEST0001 iPhone Apple-iPhone16C2/2201.170 16.1 plain

# With the cloud on, the profile carries CalDAV and CardDAV too.
!setup/apple.mobileconfig
contains <string>com.apple.caldav.account</string>
contains <string>com.apple.carddav.account</string>
contains <key>CalDAVPrincipalURL</key><string>http://nextcloud/remote.php/dav</string>
